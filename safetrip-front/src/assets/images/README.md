# Project Images

Put your custom images here for the SafeTrip frontend.

## Suggested folders

- `home/` for the main page hero and intro sections
- `tours/` for tour cards and tour details
- `places/food/` for restaurants, cafes, and food-related places
- `places/entertainment/` for entertainment and city places
- `shared/` for images reused across several pages

## Suggested naming

Use simple names such as:

- `home-hero.jpg`
- `tour-1.jpg`
- `tour-2.jpg`
- `food-1.jpg`
- `food-2.jpg`
- `entertainment-1.jpg`

After you add the files, tell me which image should go to which page or card, and I will connect them in the code.
